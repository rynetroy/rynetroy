# 🚀 Featured Projects

## 📈 Predictive Funnel Analytics

An end-to-end project looking at e-commerce customer behavior, conversion, and revenue opportunity using GA4-aligned behavioral data.

I built a classification model to identify conversion patterns and explored how those predictions could translate into potential revenue.

**Tools:** `Python` `Pandas` `NumPy` `Scikit-Learn` `XGBoost`

### Results

* **0.8014 ROC-AUC** — final XGBoost classification model
* **5.16%** — baseline conversion rate
* **~$1.97M** — model-calibrated expected revenue
* **~$1.74M** — actual revenue over the same evaluation period
* **~13.4% gap** between predicted and realized revenue

The goal wasn't just to build a model. It was to understand what the model could actually tell us about **customer behavior and revenue opportunity**.

# 🔄 `framework.py` — Not All Pain Is Progress

> **Progress isn't always about climbing higher. Sometimes the ladder disappears — and that's when you have to figure out where you're going next.**

After more than a decade in retail leadership, the store I'd built my career around closed.

Just like that, the path I'd spent years working toward wasn't there anymore.

I could have found another retail job and kept climbing.

But I kept coming back to one question:

*What if I'm not supposed to climb the same ladder anymore?*

So I went back to school.

Now I'm a **Data Science & Machine Learning student**, learning Python, statistics, SQL, machine learning, and everything else that comes with starting over in a new field.

It's humbling going from managing a business and leading a team to being the person in the room who doesn't know the answer yet.

But that's also the point.

I used to measure progress by **career height**.

Now I measure it by **what I can do that I couldn't do before**.

This little Python framework is my way of putting that idea into code. It's not meant to be a production application. It's just a personal story told in a language I'm learning.

```python
"""
NOT ALL PAIN IS PROGRESS
A Personal Framework for Career Evolution
"""

from dataclasses import dataclass, field


@dataclass
class CareerState:
    title: str
    years_built: int
    skills: list[str] = field(default_factory=list)
    progress_metric: str = "career_height"


class ProfessionalJourney:

    def __init__(self):
        self.state = CareerState(
            title="Store Director",
            years_built=10,
            skills=[
                "Leadership",
                "Operations",
                "People Management",
                "Business Decision Making",
                "Decision Making Under Pressure",
            ],
        )

    def trigger_disruption(self):
        print(">>> EVENT: Store closure announced.")
        print(">>> RESULT: The old career path is no longer available.")

    def redefine_progress(self):
        self.state.progress_metric = "capability"

        print("--- PERSPECTIVE SHIFT ---")
        print("Old metric: Career height")
        print("New metric: Capability")

    def execute_pivot(self):
        new_capabilities = [
            "Python",
            "Statistics",
            "Linear Algebra",
            "SQL",
            "Data Analysis",
            "Machine Learning",
        ]

        self.state.skills.extend(new_capabilities)

        self.state.title = (
            "Data Science & Machine Learning Student"
        )

    def calculate_trajectory(self):
        return """
Progress is not a straight line upward.

Sometimes the ladder disappears.

The old life is gone.
The foundation remains.
The direction has changed.

Not all pain is progress —
but the right kind of discomfort
builds something the old version of you didn't have.
"""


if __name__ == "__main__":
    journey = ProfessionalJourney()

    journey.trigger_disruption()
    journey.redefine_progress()
    journey.execute_pivot()

    print(journey.calculate_trajectory())
```
